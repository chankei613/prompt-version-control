macOS · 無料 · 署名/公証済み

プロンプトの変更履歴を、消さずに管理する。

プロンプトやworker定義を編集するたびに新しいバージョンとして保存。ロールバックはポインタを動かすだけで、履歴は一切消えません。

無料でダウンロード 使い方を見る

インストール不要・アカウント登録なし。ロールバックしても以前のバージョンは全て残ります。

daily-summary-prompt v2 → v3 (現在)
あなたは要約アシスタントです。
- 3行以内で要約してください。
+ 5行以内で、箇条書きで要約してください。
+ 数値や固有名詞は省略しないこと。
出力は日本語のみとする。

差分比較 — 任意の2バージョン間で何が変わったかを行単位で確認できる

AIエージェントのプロンプトを日々調整している 「前のバージョンの方が良かった」を何度も経験した どの変更で出力品質が落ちたか分からなくなる worker定義をチームで共有・追跡したい

できること

「プロンプトの履歴管理」に集中したツールです。

📜

追記専用の履歴

編集して保存するたびにバージョン1, 2, 3…と増えていきます。既存のバージョンが上書きされることはありません。

↩️

ポインタ移動だけのロールバック

ロールバックは「現在」がどのバージョンかを動かすだけ。過去のバージョンは削除されず、いつでも見返せます。

🔍

行単位の差分比較

任意の2バージョンを選んで、追加・削除された行を色分けして確認できます。

📈

バージョンごとの品質推移

外部システムがバージョンIDに紐づけて品質スコアをPOSTすれば、どの変更が効いたかが一目で分かります。

🔌

任意のAIシステムから利用可

comet-taskAI・ai-scheduler・独自スクリプト等、HTTPで読み書きできるものなら何からでも連携できます。

🔑

APIキー認証

外部システムからのアクセスはAPIキーで保護。キーはハッシュ化して保存され、発行時にのみ表示されます。

使い方は3ステップ

起動してプロンプトを作るだけ。設定はそれだけです。

1

プロンプトを作成

Key・説明・初期内容を入力して作成。これがバージョン1として保存されます。

2

編集して新バージョンを保存

内容を編集して保存すると新しいバージョンが作られます。以前のバージョンは残ったままです。

3

比較・ロールバック

差分を確認し、品質が下がっていたら以前のバージョンへロールバックします。

プロンプトを編集 → 新バージョンとして保存 → 外部システムが品質をPOST → 推移を確認・必要ならロールバック

履歴は絶対に消えない設計

ロールバックは「現在」のポインタを動かすだけ。どれだけ操作しても過去のバージョンは失われません。

Prompt Version Controlが保証すること
  • 削除されない履歴 — バージョンは追記されるのみ。ロールバックや新規保存で過去のバージョンが消えることはありません。
  • ロールバックはポインタ操作のみ — 「現在」がどのバージョンかを切り替えるだけで、新しいバージョンも古いバージョンも削除も発生しません。
  • 差分は正確に計算 — LCSアルゴリズムによる行単位の差分で、追加・削除を正確に表示します。
  • APIキーは発行時のみ表示 — 外部システムからの読み書きは認証必須。キーはハッシュ化して保存します。
